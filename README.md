# Vault Hunters Website Clone

A pixel-perfect, fully responsive clone of the Vault Hunters homepage built as a front-end practice project using **Tailwind CSS** and pure **HTML/CSS**.

## Installation

```bash
# Clone the repository
git clone https://github.com/ali-mirzaei-dev/Vault-Hunters-Website.git

# Navigate to project directory
cd Vault-Hunters-Website

# Open with Live Server or open index.html in browser
`````
